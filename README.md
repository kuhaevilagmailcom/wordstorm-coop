# WORDSTORM — 3D кооперативная игра «слово → катастрофа»

Полноценный проект браузерной 3D-игры: **Three.js + Socket.IO + Node.js + серверный AI API**.

## Что умеет

- Игроки входят в одну комнату по коду или ссылке (до 16 человек).
- WASD/стрелки — движение, мышь — камера от третьего лица, `SPACE` — прыжок, `SHIFT` — ускорение. Для смартфонов — джойстик и сенсорные кнопки.
- Каждые **10 секунд** сервер случайно выбирает игрока. У него **5,7 секунды** на ввод любого слова.
- **ИИ** по слову сам предлагает название катастрофы, предупреждение, тип атаки, подходящую модель, цвет и интенсивность; **сервер** создаёт опасности. Пример: `телефон` → дождь из объёмных 3D-смартфонов.
- Поддерживаются дождь предметов, метеориты, движущиеся насквозь арены опасности, преследующий рой, вихрь и ударные волны. Для часто встречающихся предметов есть 3D-модели, для необычных — универсальные 3D-объекты с подписанным словом.
- Сервер рассчитывает попадания, здоровье, смерть, возрождение, очки и синхронизацию игроков.
- Чат, копирование ссылки на комнату, таблица игроков, история событий, эффекты и звуки.
- Если AI API не отвечает, игра продолжает работать с процедурным запасным вариантом. **Этот запасной режим не равнозначен полноценной генерации ИИ.**

## Быстрый запуск

**Нужен хостинг, который поддерживает Node.js и WebSocket.** Обычный статический FTP-хостинг / GitHub Pages без сервера не подходит для кооператива и ИИ.

1. Установите **Node.js 20.19+** (лучше 22 LTS).
2. Скопируйте `.env.example` в `.env`, если `.env` отсутствует.
3. Укажите в `.env` значения API (или задайте их переменными окружения хостинга):

   ```env
   PORT=3000
   HCNSEC_API_BASE=https://api.hcnsec.cn/v1
   HCNSEC_API_KEY=ВАШ_СЕКРЕТНЫЙ_КЛЮЧ
   HCNSEC_MODEL=DeepSeek-V4-Pro
   ```

4. В папке проекта выполните:

   ```bash
   npm install
   npm run build
   npm start
   ```

5. Откройте `http://localhost:3000`, введите ник и код комнаты. Для игры через Интернет откройте домен с HTTPS и включённым WebSocket.

**Проверка работы:** `http://localhost:3000/api/status` покажет `aiEnabled: true`, когда сервер загрузил ключ. `/health` вернёт `ok`. Показатель `aiEnabled: true` означает, что ключ задан, но сам по себе не гарантирует успешного ответа стороннего API. Ошибки AI видны в логах Node.js, а игра переходит в запасной режим.

## Разработка

В двух терминалах: `npm run server` и `npm run dev`. Открыть `http://localhost:5173` (Vite автоматически передаёт Socket.IO и `/api` на 3000-й порт).

## Публикация

- **Render / Railway / VPS:** разверните как Node.js веб-сервис. Команда сборки: `npm install && npm run build`. Команда запуска: `npm start`. Укажите порт через `PORT` или используйте порт, предоставленный платформой.
- **Docker:** `docker build -t wordstorm .` затем `docker run -p 3000:3000 --env-file .env wordstorm`.
- **Nginx:** проксируйте HTTP **и** WebSocket `/socket.io/`; SSL/TLS — на домене. Для масштабирования на несколько отдельных Node-процессов понадобится адаптер общего состояния (например, Redis), иначе игроки одной комнаты могут попасть в разные процессы.

## Безопасность

**Файл `.env` — секретный серверный конфиг.** Он никогда не загружается в браузер: сервер отдаёт только собранный `dist/` и публичные API без ключа. **Не загружайте `.env`/приватную ZIP-сборку в публичный GitHub, публичную папку сайта или статический файловый хостинг.** Для Render, Railway и Docker удобнее указать ключ в панели переменных окружения, а не включать `.env` в образ. Если ключ когда-либо публиковался, безопаснее заменить его новым.

Слово проходит через AI как пользовательский ввод, а сервер принимает только безопасные строго ограниченные типы катастроф и параметры — ИИ не выполняет произвольный JavaScript. Не рекомендуется давать посетителям возможность вводить HTML/JS в серверные шаблоны.

## Важные ограничения

- AI API должен быть совместим с OpenAI Chat Completions `/v1/chat/completions`. Доступность и правильность указанной модели зависят от стороннего провайдера.
- ИИ строит параметрические 3D-модели из набора геометрических элементов и управляет поведением; полноценные высокополигональные меши произвольной формы требуют отдельного text-to-3D сервиса.
- Состояние комнат хранится в памяти сервера и сбрасывается при перезагрузке. До 16 игроков на комнату, сервер оптимизирован под небольшие совместные сессии.


## AI WORLDGEN — новая генерация

Теперь игрок вводит **любое описание до 220 символов**, а не одно слово. Примеры:

- `200 кубиков стоят на земле, через три секунды скачут`
- `Из земли вырастают огромные деревья`
- `Холодильники гоняются за игроками`

ИИ создаёт JSON-сцену: до трёх видов объектов, до 350 экземпляров (до 300 на один вид), для каждой модели до 18 геометрических деталей (box, sphere, cylinder, cone, capsule, torus, tube, lathe, extrude и прочие). Определяет цвет, форму, количество, способ появления, урон и **этапы поведения** (стоять → прыгать → преследовать). Это не фиксированный список названий предметов.

Сервер проверяет все входящие параметры и рассчитывает попадания; 3D-движок отображает объекты с помощью `THREE.InstancedMesh`. **Произвольный JavaScript от ИИ не исполняется.** Без работающего AI API доступен ограниченный запасной режим — полноценная генерация новых моделей требует подключённой модели с Chat Completions API.

На Render после обновления GitHub должен пройти новый deploy. Храните `HCNSEC_API_KEY` только в Environment сервера, никогда в репозитории.
